# Real Food Group Notes

An Obsidian-driven Markdown publishing site.

## Publishing

The Stove Publisher Obsidian plugin uploads notes into `content/`. GitHub Actions builds every Markdown file into a route:

```text
content/decentralized-agriculture.md
https://mattastovall.github.io/stove-notes/decentralized-agriculture/
```

The site index is generated automatically from all files in `content/`.
